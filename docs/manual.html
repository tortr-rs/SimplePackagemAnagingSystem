NAME

hoard — SimplePackagemAnagingSystem (SPAS), a package manager for Gentoo

SYNOPSIS

hoard [--root dir] command [options] [arguments]

DESCRIPTION

hoard installs, updates and removes packages from Gentoo ebuild repositories. It reads the same configuration and writes the same package database as Portage, so either can manage the system. Package names without a category are accepted; hoard asks when one is ambiguous.

COMMANDS

install, i pkg ...
Build and install packages and their dependencies.
upgrade, up
Update the whole system (install -uDN @world).
remove, rm pkg ...
Uninstall packages (-p, -y, --force).
autoremove
Uninstall packages nothing needs any more (-p, -y).
sync [repo ...]
Update the repositories. rsync trees are verified against their signed Manifests; git repositories get their commit signature checked where configured; overlays that were never fetched are cloned.
search, s regex
Search package names (-d: descriptions too).
info pkg
Versions, keywords, masks and USE flags of a package.
list [regex]
Installed packages.
files pkg
Files installed by a package.
owns path ...
Which package installed a file.
env-update
Regenerate /etc/profile.env and ld.so.conf.
verify [repo]
Check a repository against its signed Manifests, or a git repository's commit signature.
manifest pkg|dir
Write the DIST lines of an overlay package's Manifest, downloading new files.
resume
Same as install --resume.
self-update
Replace this hoard with the newest release (--check: only report). Refuses when hoard was installed as a package.

INSTALL OPTIONS

-p, --pretend
Only show what would be done.
-y, --yes
Don't ask for confirmation.
-1, --oneshot
Don't add the packages to the world file.
-u, --update
Only update when a newer version is available.
-D, --deep
Consider the whole dependency tree.
-N, --newuse
Rebuild packages whose USE flags changed.
-n, --noreplace
Skip packages that are already installed.
-f, --fetchonly
Download the sources (or binary packages) only.
-g, --getbinpkg
Use prebuilt packages from the Gentoo binhost (default when FEATURES contains getbinpkg).
-k, --usepkg
Use packages built earlier (PKGDIR), no downloads.
-b, --buildpkg
Also save each package built from source in PKGDIR (default when FEATURES contains buildpkg).
-S, --source
Build everything from source.
--nodeps
Ignore dependencies.
--autounmask=n
Don't work out package.use / keyword / license changes.
--autounmask-write
Write those changes without asking (needed with -y).
--with-bdeps=y|n
Also update/install build dependencies of installed packages (default: from EMERGE_DEFAULT_OPTS, else n).
-q, --quiet
Hide build output (it is still logged).
-jN, --jobs=N
Build up to N packages at once (default: from EMERGE_DEFAULT_OPTS, else 1).
--keep-going
After a failed build, go on with every package that doesn't depend on it (also read from EMERGE_DEFAULT_OPTS).
--resume
Carry on after a failed run: merged packages are left out, and a failed build continues from the phase it stopped in.
--skipfirst
With --resume, leave out the package that failed.
--fresh
Throw away earlier failed builds and start them over.

FAILED BUILDS

A failed build keeps its directory under /var/tmp/spas and the run is saved in /var/lib/spas/resume. If the ebuild, USE, the sources or the compiler flags change before the next try, the build starts over. When the kernel kills a compiler for lack of memory, hoard halves the -j in MAKEOPTS and runs the same phase again, down to -j1. Unknown options are an error.

SETS

@world, @system, @selected, @preserved-rebuild.

ENVIRONMENT

PORTAGE_CONFIGROOT
Read configuration from $PORTAGE_CONFIGROOT/etc/portage instead of /etc/portage.
PORTAGE_BINHOST
Binary package host to use instead of the official Gentoo one.
NO_COLOR
Disable colored output.

FILES

/etc/portage/
make.conf, package.*, repos.conf, make.profile: the same configuration Portage uses.
/var/db/pkg/
Installed package database.
/var/lib/portage/world
Packages you asked for.
/var/lib/portage/preserved_libs_registry
Libraries kept for programs that still need them.
/var/cache/distfiles/
Downloaded sources (DISTDIR).
/var/cache/binpkgs/
Your own binary packages (PKGDIR).
/var/cache/hoard/
Metadata cache, binhost index and downloaded binary packages.

EXAMPLES

hoard sync && hoard upgrade          # the usual
hoard install -p app-editors/vim     # what would it do?
hoard install -g -j4 www-client/firefox
hoard owns /usr/bin/jq
