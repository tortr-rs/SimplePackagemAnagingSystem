About

SPAS (SimplePackagemAnagingSystem) is a package manager for Gentoo. Its command is hoard.

It is not a front end for Portage. hoard reads the Gentoo repositories itself, resolves dependencies, runs ebuilds in its own EAPI 7/8/9 bash environment, merges the result and records it, all without Python and without any part of Portage. It is a single binary written in Rust.

hoard keeps Portage's on-disk formats (/etc/portage, /var/db/pkg, the world file, distfiles, binary packages), so you can switch back and forth or use both on the same machine.

Example

# hoard install -p app-misc/jq
>>> Calculating dependencies...

[binary N    ] dev-libs/oniguruma-6.9.10::gentoo USE="-crnl-as-line-terminator -static-libs" ABI_X86="-32 (64) (-x32)" 270.0 KiB
[ebuild N    ] app-misc/jq-1.8.2::gentoo USE="oniguruma -static-libs (-test)"

Total: 2 packages, size of downloads: 270.0 KiB

The first package comes prebuilt from the official Gentoo binhost, chosen because its USE flags match; the second is built from source. See Features.

2026-11-11 — hoard 0.3.0 released
hoard is now a Gentoo package: add the spas overlay and hoard install sys-apps/spas, after which hoard upgrade keeps it current. Hand-installed binaries get hoard self-update. New hoard manifest writes overlay Manifests (identical to ebuild ... manifest). Fixes --root=DIR, which was ignored. Download.

preserve-libs (with @preserved-rebuild), parallel builds (-jN), your own binary packages (FEATURES=buildpkg), autounmask-style configuration changes, and OpenPGP checks of git commit signatures. hoard sync now clones overlays that were never fetched.
